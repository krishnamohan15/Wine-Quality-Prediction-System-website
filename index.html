Computer Networks

Where networking fits in.

The project can be deployed as a network-accessible ML service.

🔗

Client–Server Architecture

The client sends a prediction request while the server processes the request and returns the result.

🌐

IP Addressing

📦

Data Transmission

Wine parameters are transmitted from the client to the prediction service.

🔄

Request & Response

The client makes a request and receives the predicted quality as the server response.

LAN / Internet

The application can be deployed inside a local network or made accessible through the Internet.
